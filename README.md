# Tools

Small single-file HTML tools, mostly built with help from LLMs. Each one is a
plain `.html` file you can read with View Source.

The [colophon](https://tools.michaelwarkentin.com/colophon) lists every
tool's commit history, with links to the chats and agent sessions that wrote
them. The code lives in
[mwarkentin/tools](https://github.com/mwarkentin/tools).

## Infrastructure

- [Cron explainer](https://tools.michaelwarkentin.com/cron-explainer): describe a cron expression in plain English and list its next runs in Toronto time, or any other time zone
- [Kubernetes quantities](https://tools.michaelwarkentin.com/k8s-quantity): convert and add up CPU and memory quantities like `500m` and `2Gi`

## Text and logs

- [Log prettifier](https://tools.michaelwarkentin.com/log-prettifier): turn pasted JSON or logfmt logs into readable lines, filter them by level, and copy the result as Markdown
